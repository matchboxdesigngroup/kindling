== Description ==
Kindling is a modern, responsive, and accessible WordPress block theme built for Full Site Editing (FSE).
Created by [Matchbox Design Group](https://matchboxdesigngroup.com), it provides a flexible foundation for designing and building content-rich websites.

The theme features design tokens managed through `theme.json`, global color palettes, typography controls, and pre-built patterns for quick page assembly.
It can be used as a starter theme or as a parent theme for custom client projects.

== Installation ==
1. Upload the `kindling` folder to your `/wp-content/themes/` directory.
2. Activate the theme from your WordPress dashboard under **Appearance → Themes**.
3. Open the **Site Editor** to begin customizing templates, parts, and global styles.

== Features ==
* Full Site Editing (FSE) support
* Configurable design tokens via `theme.json` 
* Predefined color palettes and gradients
* Custom block styles and pattern library
* Accessibility-conscious markup and contrast
* Lightweight, performance-focused build
